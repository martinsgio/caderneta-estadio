Backup e planilha

As fotos ficam guardadas no Supabase e não entram no backup, só os dados dos jogos.

Para cadastrar jogos antigos de uma vez, monte uma planilha com as colunas data, mandante, gols_mandante, gols_visitante, visitante, competicao, estadio, cidade, pais e salve como CSV. Datas no formato 25/12/2019. Jogos repetidos são ignorados.
